# CLAUDE.md — сервер каталога «Туман»

Этот файл Claude Code читает в начале каждой сессии.

## Что это

Курсовой проект ИТМО «Туман — Языки России» (12 октября – 30 ноября 2026, защита 30 ноября). Продукт — Android-приложение с карточками по башкирскому языку и интервальным повторением. Этот репозиторий — **сервер каталога готовых наборов**: приложение запрашивает список наборов и скачивает выбранный набор на устройство. Всё остальное приложение делает без интернета.

Приложение, ТЗ и общие правила команды — в репозитории `tuman-langs/tuman-langs-mobile` (`CLAUDE.md`, `docs/tz.md`, `docs/product.md`). Если он склонирован рядом, запускай Claude Code с `--add-dir ../tuman-langs-mobile`.

## Что должен уметь сервер (из ТЗ)

- Отдавать список наборов и содержимое набора в JSON (черновик API — `docs/api.md`).
- В каталоге не менее 3 наборов по башкирскому, всего 100+ карточек, в том числе по аффиксам.
- Формат наборов позволяет добавлять языки без изменения кода (`content/README.md`).
- Сервер работает на время проверки и защиты; ошибки сети не должны ронять приложение — это зона mobile, но ответы сервера должны быть предсказуемыми (коды ошибок, JSON).

Ответственный за сервер — Василенко Арина (backend-разработчик). Наборы карточек — Богданов Егор (контент-лид). Ревьюер PR по умолчанию — руководитель, GitHub `@Mimir-tu`.

## Проверка перед PR

Стек ещё не выбран. Когда появится код, впиши сюда команды тестов и запуска, например `./gradlew test` или `pytest`. Пока проверка — валидность JSON в `content/` и соответствие `docs/api.md`.

## Правила для Claude

1. **Объясняй, а не только пиши код.** Участники — первокурсники; по правилам ИТМО каждый должен понимать и защитить любую часть работы, включая сделанную с ИИ.
2. **Сначала план, потом код** для всего, что больше пары файлов.
3. **Держись ТЗ и MVP.** Регистрация, синхронизация, ИИ-функции, озвучка в MVP не входят.
4. **Не придумывай языковой контент.** Переводы и правила башкирского проверяет контент-лид по словарям. Не выдавай сгенерированные переводы за проверенные.
5. **Не храни секреты в репозитории.** Ключи хостинга и пароли — только в переменных окружения или `.env`.
6. Предлагай простые решения: сервер маленький, его должен понимать и поддерживать один первокурсник.
