# Наборы карточек

Один набор — один JSON-файл в этой папке, имя файла = `id` набора (`ba-basic-words.json`). Формат согласует контент-лид; стартовый вариант:

```json
{
  "id": "ba-letters",
  "language": "ba",
  "title": "Буквы башкирского алфавита",
  "description": "9 букв, присутствующих в башкирском алфавите, но не в русском",
  "version": 1,
  "sources": ["Русско-башкирский словарь под редакцией З. Г. Ураксина, 2005", "Башкирско-русский словарь под редакцией З. Г. Ураксина, 1996"],
  "cards": [
	{
	"id": "ba-letters-0001", 
	"front": "Ғ ғ", 
	"back": "5-ая буква в башкирском алфавите. \nПроизносится как \"Г\" и \"Х\" одновременно.", 
	"example": "Ғалим - Учёный", 
	"tags": ["буква", "согласная"]
	}
  ]
}
```

Правила из ТЗ:
- минимум 3 набора (например «Базовые слова», «Фразы на каждый день», «Аффиксы»), всего 100+ карточек;
- каждый перевод сверен минимум с двумя источниками, источники перечислены в `sources`;
- все буквы башкирского алфавита (ә, ө, ү, ғ, ҡ, ң, ҙ, ҫ, һ) — в UTF-8, без замены похожими латинскими или кириллическими;
- `id` карточек уникальны внутри набора и не меняются после публикации: по ним приложение хранит историю повторений.

Добавлять наборы удобно прямо на сайте GitHub: Add file → Create new file → при сохранении «Create a new branch for this commit and start a pull request».
