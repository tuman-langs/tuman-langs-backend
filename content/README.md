# Наборы карточек

Один набор — один JSON-файл в этой папке, имя файла = `id` набора (`ba-basic-words.json`). Формат согласует контент-лид; стартовые варианты:

1) Для букв:
```json
{
  "id": "ba-letters",
  "language": "ba",
  "title": "Буквы башкирского алфавита",
  "description": "9 букв, присутствующих в башкирском алфавите, но не в русском",
  "version": 1,
  "sources": ["Русско-башкирский словарь под редакцией З. Г. Ураксина, 2005", "Башкирско-русский словарь под редакцией З. Г. Ураксина, 1996"],
  "cards": [
	{
	"id": "ba-letters-0001", 
	"front": "Ғ ғ", 
	"back": "5-ая буква в башкирском алфавите.",
	"pronunciation": "Произносится как \"г\" и \"х\" одновременно.",
	"notes": "-",
	"example": "Ғалим",
	"example_translation": "Учёный",
	"tags": ["буква", "согласная"]
	},
 	{
	"id": "ba-letters-0004", 
	"front": "Ң ң", 
	"back": "19-ая буква в башкирском алфавите.",
	"pronunciation": "Чтобы произнести, нужно произвести носовой звук \"н\".", 
	"notes": "Слова в башкирском никогда не начинаются с буквы ң!", 
	"example": "Яңы Йыл",
	"example_translation": "Новый Год", 
	"tags": ["буква", "согласная"]
	}
  ]
}
```

```json
{
  "id": "ba-basic-words",
  "language": "ba",
  "title": "Базовые слова",
  "description": "Слова, использующиеся в повседневной речи",
  "version": 1,
  "sources": ["Русско-башкирский словарь под редакцией З. Г. Ураксина, 2005", "Башкирско-русский словарь под редакцией З. Г. Ураксина, 1996"],
  "cards": [
	{

	"front": "Һаумы!",

	"pronunciation": "[һ́аумы]",
	"notes": "Это приветствие - для друга!",
	"example": "Һаумы, Туман!", 
	"example_translation": "Здравствуй, Туман!",

	}

```
3) Для аффиксов:
```json
{
  "id": "ba-basic-affixes",
  "language": "ba",
  "title": "Базовые аффиксы",
  "description": "Аффиксы, необходимые начинающим",
  "version": 1,
  "sources": ["Русско-башкирский словарь под редакцией З. Г. Ураксина, 2005", "Башкирско-русский словарь под редакцией З. Г. Ураксина, 1996"],
  "cards": [
	 {
      	 "id": "ba-basic-affixes-0001",
         "front": "-лар / -ләр / -дар / -дәр / -тар / -тәр / -ҙар / -ҙәр",
         "back": "Аффикс множественного числа.",
         "pronunciation": "[лар / ләр / дар / дәр / тар / тәр / ҙар / ҙәр]",
         "notes": "Выбор варианта зависит от последней буквы основы слова. Например: -лар/-ләр после гласных, р, у, й; -тар/-тәр после глухих согласных.",
         "example": "Китаптар",
         "example_translation": "Книги",
         "tags": ["аффикс", "существительное", "множественное-число"]
   	 }
  ]
}
```
### Обязательные поля для каждой карточки:
* **`id`** (string): Уникальный ID карточки (например, `ba-letters-0001`). Не менять после публикации.
* **`front`** (string): Лицевая сторона. Для букв обязательно указывать оба регистра (`Ң ң`). Для аффиксов - перечисление вариантов через косую черту (`-лар / -ләр`).
* **`back`** (string): Основное значение, перевод или краткое описание.
* **`pronunciation`** (string): Подсказка по произношению или транскрипция.
* **`notes`** (string): Дополнительные примечания. Если заметок нет, ставится дефис `"-"`.
* **`example`** (string): Пример использования на башкирском языке.
* **`example_translation`** (string): Перевод примера на русский язык.
* **`tags`** (array of strings): Теги для фильтрации, для аффиксов могут использоваться для полиморфной сборки слов (например: `["аффикс", "падеж", "местный"]`).

Правила из ТЗ:
- минимум 3 набора (например «Базовые слова», «Фразы на каждый день», «Аффиксы»), всего 100+ карточек;
- каждый перевод сверен минимум с двумя источниками, источники перечислены в `sources`;
- все буквы башкирского алфавита (ә, ө, ү, ғ, ҡ, ң, ҙ, ҫ, һ) — в UTF-8, без замены похожими латинскими или кириллическими;
- `id` карточек уникальны внутри набора и не меняются после публикации: по ним приложение хранит историю повторений.

Добавлять наборы удобно прямо на сайте GitHub: Add file → Create new file → при сохранении «Create a new branch for this commit and start a pull request».
