# API каталога

Сервер отдаёт JSON в UTF-8: заголовок `Content-Type: application/json; charset=UTF-8`. Адрес сервера: **https://tuman-langs-backend.onrender.com** — например, https://tuman-langs-backend.onrender.com/sets. Локально сервер работает на http://localhost:8080 (запуск — в `README.md`). После простоя первый ответ приходит примерно через минуту — см. «Сервер просыпается после простоя».

## GET /sets

Список наборов без карточек, по алфавиту `id`. Наборы берутся из файлов `content/*.json`; файл, который не удалось прочитать, в список не попадает.

| Поле | Тип | Что это |
|---|---|---|
| `id` | string | id набора, по нему набор скачивается через `GET /sets/{id}` |
| `language` | string | код языка, например `"ba"` |
| `title` | string | название набора |
| `description` | string | краткое описание |
| `version` | integer | версия набора; увеличивается при любом изменении набора |
| `card_count` | integer | число карточек в наборе |

Пример — настоящий ответ сервера:

```
GET /sets

200 OK
Content-Type: application/json; charset=UTF-8
```
```json
[
  {
    "id": "ba-letters",
    "language": "ba",
    "title": "Буквы башкирского алфавита",
    "description": "9 букв, присутствующих в башкирском алфавите, но не в русском",
    "version": 1,
    "card_count": 9
  }
]
```

Если наборов нет — пустой список `[]`.

## GET /sets/{id}

Набор целиком со всеми карточками, поля — как в файле набора (`content/README.md`). `{id}` — `id` набора из `GET /sets`. Если набора нет — `404` и `{"error": "set_not_found"}`.

Поля набора:

| Поле | Тип | Что это |
|---|---|---|
| `id` | string | id набора |
| `language` | string | код языка, например `"ba"` |
| `title` | string | название набора |
| `description` | string | краткое описание |
| `version` | integer | версия набора; увеличивается при любом изменении набора |
| `sources` | array of string | словари и учебники, по которым сверены переводы |
| `cards` | array of object | карточки, порядок — как в файле набора |

Поля карточки:

| Поле | Тип | Обязательное | Что это |
|---|---|---|---|
| `id` | string | да | id карточки; не меняется после публикации, по нему приложение хранит историю повторений |
| `front` | string | да | лицевая сторона |
| `back` | string | да | перевод или описание |
| `tags` | array of string | да | теги, может быть пустым списком |
| `pronunciation` | string | нет | подсказка по произношению |
| `notes` | string | нет | примечание |
| `example` | string | нет | пример на башкирском |
| `example_translation` | string | нет | перевод примера, бывает только вместе с `example` |

Необязательного поля, которого нет у карточки, в ответе тоже нет: сервер не присылает `"notes": null`.

Пример — настоящий ответ сервера (показаны 2 карточки из 9):

```
GET /sets/ba-letters

200 OK
Content-Type: application/json; charset=UTF-8
```

```
GET /sets/no-such-set

404 Not Found

```
```json

```

## Ошибки

Тело любой ошибки — `{"error": "<код>"}`.

| Код ответа | `error` | Когда |
|---|---|---|
| `404` | `set_not_found` | набора с таким id нет (`GET /sets/{id}`) |
| `500` | `internal_error` | неожиданная ошибка на сервере, например не найдена папка с наборами. Подробности — только в логе сервера |

## Сервер просыпается после простоя

Сервер размещён на бесплатном тарифе Render (согласовано в задаче #7). После 15 минут без запросов он засыпает, и первый ответ после этого приходит **примерно через минуту**; следующие — сразу. Специально «будить» сервер запросами по расписанию не будем.

Что это значит для клиента:

- ожидание ответа — **60 секунд** (обычные 10 с не хватит, и вместо каталога будет ошибка сети);
- если ответа нет дольше нескольких секунд — показывать «Сервер просыпается…» (tuman-langs/tuman-langs-mobile#31).

Перед проверкой и защитой backend-разработчик заранее открывает `/sets`, чтобы сервер успел проснуться.
