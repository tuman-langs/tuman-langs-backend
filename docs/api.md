# API каталога — черновик

Стартовая точка для обсуждения; окончательный вариант утверждает backend-разработчик вместе с Android-разработчиками.

## GET /sets

Список наборов без карточек.

```json
[
  {"id": "ba-basic-words", "language": "ba", "title": "Базовые слова",
   "description": "Частотные слова для начала", "version": 1, "card_count": 40}
]
```

## GET /sets/{id}

Набор целиком в формате `content/README.md`. Если набора нет — `404` и `{"error": "set_not_found"}`.
