# Инструкция по развертыванию и обслуживанию сервера (tuman-langs-backend)

## 1. Информация о хостинге и размещении
- **Платформа:** Render (бесплатный тариф, согласовано в #7).
- **Адрес сервера:** `https://tuman-langs-backend.onrender.com`
- **Ветка сборки:** `main` (автоматическая сборка при пуше в `main`, критически важно для обновления наборов).
- **Доступы:** Учётные данные и доступы к панели Render имеются у руководителя проекта (без публикации секретов в репозитории).
- **Просмотр логов в панели Render:** 
  1. Войти в аккаунт Render и открыть сервис бэкенда (`tuman-langs-backend`).
  2. Перейти на вкладку **Logs** в левом меню для мониторинга в реальном времени.
- **Перезапуск сервера в панели Render:**
  1. Открыть сервис `tuman-langs-backend` на Render.
  2. Нажать кнопку **Manual Deploy** в правом верхнем углу и выбрать **Deploy latest commit** (для обычного перезапуска). *Примечание: Clear build cache используется только в случае проблем со сборкой.*

## 2. Обслуживание и просмотр логов
Логи отслеживаются через веб-панель Render (вкладка Logs) или через CLI.

## 3. Проверка «холодного старта» (засыпание)
Бесплатный тариф Render уходит в спящий режим при отсутствии активности.
- **Время пробуждения:** Первый ответ занимает **около минуты** (согласно `docs/api.md`, раздел «Сервер просыпается после простоя»).
- **Таймаут в приложении:** Установлен таймаут **60 секунд** с выводом надписи «Сервер просыпается…» (tuman-langs/tuman-langs-mobile#31).
- **Подготовка к защите:** Перед демонстрацией за 2–3 минуты сделать тестовый запрос `GET /sets`.

## 4. Резервный запуск (Локальный запуск на ноутбуке)
Если внешняя инфраструктура Render недоступна во время защиты:

1. **Запуск бэкенда:**
   - macOS / Linux: `./gradlew :server:run`
   - Windows: `.\gradlew.bat :server:run`
   (Сервер запускается локально по адресу `http://localhost:8080`).

2. **Настройка мобильного приложения:**
   - Адрес задается через конфигурационный файл (способ уточняется по итогам согласования в #31).
   - **Для эмулятора Android:** используется адрес `http://10.0.2.2:8080`.
   - **Для реального телефона:** телефон и ноутбук должны находиться в **одной Wi-Fi сети** (детали доступа по `http://` настраиваются в рамках #31).
