# Инструкция по развертыванию и обслуживанию сервера (tuman-langs-backend)

## 1. Информация о хостинге и размещении
- **Платформа:** Render (бесплатный тариф).
- **Адрес сервера:** `https://tuman-langs-backend.onrender.com`
- **Ветка сборки:** `main` (автоматически собирается при пуше в `main`, гарантирует попадание новых наборов).
- **Доступы:** Учётные данные и доступы к панели Render имеются у руководителя проекта (без публикации паролей в репозитории).
- **Просмотр логов в панели Render:** 
  1. Войти в аккаунт Render и открыть сервис бэкенда (`tuman-langs-backend`).
  2. Перейти на вкладку **Logs** в левом меню для мониторинга в реальном времени.
- **Перезапуск сервера в панели Render:**
  1. Открыть сервис на Render.
  2. Нажать кнопку **Manual Deploy** в правом верхнем углу.
  3. Выбрать **Clear build cache & deploy** для полного перезапуска.

## 2. Обслуживание и просмотр логов
Логи также можно отслеживать через CLI сервиса Render или непосредственно в веб-панели управления.

## 3. Проверка «холодного старта» (засыпание)
Бесплатный тариф Render засыпает при отсутствии активности. 
- **Время пробуждения:** Первый запрос выполняется около **около минуты** (см. `docs/api.md`, раздел «Сервер просыпается после простоя»).
- **Таймаут в приложении:** Установлен таймаут **60 секунд** с отображением надписи «Сервер просыпается…» (tuman-langs/tuman-langs-mobile#31).
- **Подготовка к защите:** За 2–3 минуты до демонстрации необходимо сделать тестовый запрос `GET /sets`.

## 4. Резервный запуск (Локальный запуск на ноутбуке)
Если внешняя инфраструктура недоступна во время защиты, бэкенд запускается локально:

1. **Запуск бэкенда:**
   - На macOS / Linux: `./gradlew :server:run`
   - На Windows: `.\gradlew.bat :server:run`
   (Сервер запускается по адресу `http://localhost:8080`).

2. **Настройка мобильного приложения:**
   - Адрес задается через конфигурационный файл (например, `local.properties` или `app/build.gradle.kts`, согласовано в #31).
   - **Для эмулятора Android:** используется адрес `http://10.0.2.2:8080`.
   - **Для реального телефона:** телефон и ноутбук должны находиться в **одной Wi-Fi сети**. Убедитесь, что реверансы в сторону безопасности Android разрешают незашифрованный `http://` трафик (согласно договорённости в #31).
