# Инструкция по развертыванию и обслуживанию сервера (tuman-langs-backend)

## 1. Информация о хостинге и размещении
- **Платформа:** Деплой сервера выполняется согласно конфигурации проекта.
- **Доступы:** Учетные данные, токены и секреты хостинга хранятся у руководителя проекта и передаются через переменные окружения (`ENV`). В репозитории секретные данные отсутствуют.

## 2. Обслуживание и просмотр логов
- **Просмотр логов:** Выполняется в панели хостинга или через CLI сервиса развертывания.
- **Перезапуск сервера:** Перезапуск приложения осуществляется через перезапуск сервиса в панели управления хостингом или повторным деплоем ветки `main`.

## 3. Проверка «холодного старта» (засыпание)
- Бесплатные тарифы могут уходить в спящий режим при отсутствии активности.
- **Инструкция по пробуждению:** Перед демонстрацией необходимо за 2–3 минуты сделать тестовый запрос `GET /sets`.
- **Таймаут:** Первый ответ («холодный старт») занимает несколько секунд. В приложении установленного таймаута в 10 секунд достаточно.

## 4. Резервный запуск (Локальный запуск на ноутбуке)
Если внешняя инфраструктура недоступна во время защиты, сервер запускается локально:

1. **Запуск бэкенда:** `./gradlew run`
2. **Перенаправление мобильного приложения:** В файле `BuildConfig` укажите адрес локального сервера (`http://10.0.2.2:8080` для эмулятора или `http://<IP_компьютера>:8080` для устройства).
